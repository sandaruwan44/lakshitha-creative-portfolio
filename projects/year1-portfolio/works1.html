Lewis Hamilton — Scuderia Ferrari

Lewis Hamiltonをテーマに、カード、タイムライン、数字のアニメーションを組み合わせたウェブサイトを制作しました。

URL

サイトを開く / Open project

担当

・ページレイアウトと配色
・HTML / CSS / JavaScriptによるフロントエンド制作
・画像アセットの配置とインタラクションの実装

サイトの目的

選手の紹介、記録、キャリアの流れを整理し、スクロールに合わせた見せ方とページ構成を学ぶための作品です。

ターゲット

・Lewis HamiltonやF1に関心のある人
・モータースポーツのビジュアル表現を楽しみたい人

デザインについて

赤をアクセントに、透過感のあるカードと背景のグラフィックを組み合わせています。静止画のヒーロー、タイムライン、カウントアップを配置しました。

使用した技術 / スキル

・HTML5（ページ構造）
・CSS3（レイアウト・配色・レスポンシブ対応）
・JavaScript（ブラウザー上のインタラクション）
・画像アセットの配置とスタイリング

コーディングについて

・IntersectionObserverによるスクロール表示
・JavaScriptによる数字のカウントアップ
・ヒーロー画像のパララックスとスムーススクロール
・CSSによるカードとタイムラインのレイアウト
